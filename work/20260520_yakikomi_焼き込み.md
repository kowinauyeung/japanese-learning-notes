## 📌 この文での使われ方

**元の文：** アクター情報・遷移先は通知 row に焼き込む

**文中での役割（日本語）：**
「焼き込む」はこの文の述語で、「アクター情報と遷移先（画面遷移の行き先）を、通知の row（行データ）の中に直接埋め込んで固定する」という意味で使われている。システム設計・データ設計の文脈で、情報を動的に参照するのではなく静的に保持することを表している。

**文中での役割（廣東語）：**
「焼き込む」係呢句嘅述語，意思係「將 actor 資訊同畫面跳轉目標，直接固定喺 notification 嘅 row（資料列）入面」。係 system 設計嘅語境下，意思係唔靠 runtime 動態查詢，而係靜態地將資訊 hardcode / embed 落去個 record 度。

整句嘅廣東語翻譯：「Actor 資訊同 transition destination，直接 embed 落通知嘅 row 入面（唔靠動態查詢）。」

---

**【日本語】**
「焼き込む」とは、情報やデータをある媒体・構造の中に直接かつ永続的に埋め込むことを意味する動詞。元来は写真や映像の焼き付けから来ており、あとから変更しにくい形で記録することを含意する。システム開発・データ設計の文脈では「データを動的に参照せず、レコード内に直接持たせる（いわゆる非正規化・denormalization）」ことを指して使われることが多い。

**【廣東語】**
「焼き込む」係指將資訊直接、永久性地 embed 入某個媒介或資料結構入面。原本係攝影／影像嘅用語（沖曬、燒錄），引申到 software 設計就係指：唔靠 foreign key 或 runtime join 去查詢，而係直接將資料 denormalize 落個 record 入面保存。廣東話可以講「燒入去」、「直接寫死喺度」、「embed 落個 row 度」。

## 🌐 文脈別の意味 (Context-Dependent Meanings)

### 意味 ①：映像・写真の焼き付け

**日本語の説明：**
フィルムや映像に画像・テキストを直接露光・合成して記録すること。字幕やタイムスタンプを映像に直接合成する場合などに使う。

**例文：**
> タイムコードを映像に焼き込んで納品した。
> （意味：タイムコードを映像に直接合成して納品した）

**廣東語（Cantonese）：** 將 timecode 直接燒入片段入面再交貨。
**使う場面：** 映像制作・放送業界でよく使われる。

---

### 意味 ②：データの非正規化・静的埋め込み（IT・システム設計）

**日本語の説明：**
データベースやシステム設計において、動的に参照するのではなく、情報をレコードやオブジェクトの中に直接保持させること。変更耐性よりも参照速度や独立性を優先するときに行う。

**例文：**
> 送信時点のユーザー名を通知レコードに焼き込んでおくことで、アカウント削除後も履歴が残る。
> （意味：ユーザー名をレコードに直接保存しておくことで、アカウントが消えても記録が参照できる）

**廣東語（Cantonese）：** 喺發送嗰刻將 username 直接 embed 落通知 record 入面，即使之後個 account 被刪除，歷史紀錄都仲係睇得到。
**使う場面：** バックエンド設計・DB 設計のレビューや議論でよく出てくる表現。

---

### 意味 ③：ハードコード・設定の固定化（広義）

**日本語の説明：**
値や設定をコードや設定ファイルに直接書き固めてしまうこと。いわゆる hardcode に近いニュアンス。

**例文：**
> 環境変数を使わずに URL を焼き込んでしまっている。

**廣東語（Cantonese）：** 冇用 environment variable，直接將 URL hardcode 落去。
**使う場面：** コードレビューで問題点として指摘するときなど。

## 🗣️ 使い方・ニュアンス (Usage & Nuance)

**いつ使う：** IT・システム設計の文脈では「denormalize して値を直接持たせる」という設計判断を表すときに使う。映像では「ハードサブタイトル」や「タイムコード合成」などを指す。どちらも「あとから変えにくい形で固定する」という含意がある。

**廣東語で言うと：** 「燒入去」「直接 embed 落去」「寫死喺度」。IT の文脈では「非正規化（denormalize）して data 直接存落 record 入面」と言えば通じる。

**注意点：** 「焼き込む」は中立的な動詞だが、文脈によってはアンチパターンへの批判（hardcode しすぎ）として使われることもある。設計議論では意図的な選択か問題のある設計かをセットで判断する必要がある。類似表現：「埋め込む（うめこむ）」（より汎用）、「持たせる」（データを保持させる）、「denormalize する」（英語由来の技術用語）。

## 🔗 関連語 (Related Words)

- **埋め込む（うめこむ）** — より汎用的な「埋め込む」。焼き込むより固定のニュアンスが薄い
- **ハードコード（hard code）する** — プログラムコードに値を直書きする場面に特化
- **非正規化（ひせいきか）/ denormalize** — DB 設計用語として同じ概念を指す
- **持たせる** — 「データをカラムに持たせる」など、設計議論で頻出の柔らかい表現
