**【日本語】**
クライアントが一定の間隔でサーバーや外部リソースに対して定期的に問い合わせを行い、新しいデータや状態変化があるかどうかを確認する通信方式。サーバー側から能動的に通知を送るプッシュ型（push）とは対照的に、クライアント側が繰り返しリクエストを送る受動的な仕組みである。シンプルな実装が可能な反面、不要なリクエストが増えてサーバー負荷（ふか）やネットワークの無駄（むだ）が生じやすい。

**【廣東語】**
Client 定時向 server 查詢有冇新資料或者狀態變化嘅通訊方式。唔係等 server 主動通知，而係 client 自己不斷去問。實現簡單，但係會產生好多無謂嘅 request，浪費資源。

## 🌐 文脈別の意味 (Context-Dependent Meanings)

### 意味 ①：定期ポーリング（Fixed-interval Polling）

**日本語の説明：**
一定の時間間隔（例：毎秒、毎5分）でリクエストを送り続ける、最も基本的なポーリング方式。

**例文：**

> このアプリは5秒ごとにAPIをポーリングして最新データを取得（しゅとく）している。
> （意味：5秒に一回APIに問い合わせて新しいデータを取ってくる仕組みになっている。）

**廣東語（Cantonese）：** 呢個 app 每隔5秒向 API 查詢一次，攞最新嘅資料。
**使う場面：** シンプルなデータ同期、リアルタイム性がそこまで必要ない場面。

---

### 意味 ②：ロングポーリング（Long Polling）

**日本語の説明：**
クライアントがリクエストを送った後、サーバーは新しいデータが生じるまでレスポンスを保留（ほりゅう）し、データが準備でき次第返す方式。通常のポーリングより効率的で、WebSocketが使えない環境でのリアルタイム通信の代替として使われる。

**例文：**

> WebSocketが使えない環境では、ロングポーリングでリアルタイム通知（つうち）を実現（じつげん）することがある。
> （意味：WebSocketが利用できないとき、ロングポーリングで似たような動きを実現することがある。）

**廣東語（Cantonese）：** 喺唔支援 WebSocket 嘅環境下，可以用 long polling 嚟模擬 real-time 通知。
**使う場面：** チャットアプリ、通知システムなど、リアルタイム性が必要だがWebSocketが使えない場面。

## 📝 例文 (Example Sentences)

1. ポーリング方式はシンプルだが、サーバー負荷（ふか）が高くなりやすいという欠点（けってん）がある。
   → 廣東語：Polling 方式實現簡單，但缺點係容易令 server 負擔過重。

2. ポーリングの代わりにWebhookを使えば、不要なリクエストを減らせる。
   → 廣東語：用 webhook 取代 polling 嘅話，可以減少無謂嘅 request。

3. 今のシステム、ポーリングで毎秒叩いてるけど、さすがにしんどくない？
   → 廣東話：而家個 system 每秒都 polling 一次，咁唔係咁好㗎？

## 🗣️ 使い方・ニュアンス (Usage & Nuance)

**いつ使う：** システム設計、API 設計、インフラ議論など技術的な文脈で使われる。「ポーリングする」という動詞形もよく使われる。

**廣東語で言うと：** 「輪詢」（技術文書での正式な漢字表記）または「定時查詢」。口語では「polling」そのままで通じる。

**注意点：** ポーリングと対比される概念を一緒に覚えると理解が深まる：

- **Push 型 / Webhook** — サーバーが変化を検知して能動的に通知する
- **WebSocket** — 双方向の常時接続でリアルタイム通信
- **SSE（Server-Sent Events）** — サーバーからクライアントへの一方向ストリーム

ポーリングは実装が簡単な分、スケールしにくいトレードオフがあるため、負荷や頻度を考慮した設計が重要。

## 🔗 関連語 (Related Words)

- **プッシュ通知（push つうち）** — サーバー側から能動的に送る方式。ポーリングの対義。
- **Webhook** — イベント発生時にサーバーが指定URLへ POST する仕組み。
- **WebSocket** — 持続的な双方向通信チャネル。リアルタイム性が高い。
- **SSE（Server-Sent Events）** — サーバーからの一方向ストリーミング通信。
- **イベント駆動（えんどりゅう）** — イベント発生時のみ処理するアーキテクチャ思想。
