**【日本語】**
同じ操作を何度繰り返しても、結果が最初の一回と変わらない性質のこと。数学・コンピュータサイエンス・APIの設計などで用いられる概念である。例えば、DELETE リクエストを複数回送っても、リソースはすでに削除されているため結果は同じになる。

**【廣東語】**
指同一個操作，無論執行幾多次，結果都同執行一次係一樣嘅性質。喺數學、Computer Science、API 設計入面係一個非常重要嘅概念。例如 HTTP 嘅 PUT 或者 DELETE request，理論上係 idempotent 嘅——send 幾多次都好，最終結果唔會變。

---

## 🌐 文脈別の意味 (Context-Dependent Meanings)

### 意味 ①：数学における冪等性

**日本語の説明：**
ある演算 f において、f(f(x)) = f(x) が成り立つ性質。例えば「絶対値を取る」操作は冪等である。

**例文：**

> 絶対値（ぜったいち）を取る操作は冪等性を持つ。
> （意味：絶対値を取る演算は、何度繰り返しても結果が変わらない。）

**廣東語（Cantonese）：** 喺數學入面，一個運算 f 如果滿足 f(f(x)) = f(x)，咁就叫做具有冪等性。例如取絕對值呢個操作就係 idempotent。
**使う場面：** 数学・代数学の論文や教科書

---

### 意味 ②：HTTP / API設計における冪等性

**日本語の説明：**
同じHTTPリクエストを複数回送信しても、サーバーの状態が変わらないこと。GET、PUT、DELETE は冪等だが、POST は一般的に冪等ではない。

**例文：**

> PUT メソッドは冪等性（べきとうせい）があるため、同じリクエストを何度送っても安全（あんぜん）だ。
> （意味：PUTは何度送っても結果が同じなので、安心して再送できる。）

**廣東語（Cantonese）：** 喺 HTTP 設計入面，PUT 同 DELETE 係 idempotent——即係話，send 幾多次 request，server 嘅狀態都係一樣。但係 POST 就唔係，因為每次 POST 都可能 create 一個新 resource。
**使う場面：** バックエンド開発、REST API 設計の議論

---

### 意味 ③：分散システム・メッセージキューにおける冪等性

**日本語の説明：**
メッセージやジョブが重複して処理されても、副作用が発生しないように設計すること。ネットワーク障害による再送処理を安全にするために重要な概念。

**例文：**

> このワーカーは冪等性（べきとうせい）を保証しているので、メッセージが二重に届いても問題ない。
> （意味：同じジョブが二回来ても、一回分の処理しか行われない。）

**廣東語（Cantonese）：** 喺 distributed system 或者 message queue（例如 Kafka、SQS）入面，冪等性係指即使同一條 message 被處理咗多次，最終結果都係一樣，唔會出現重複副作用。呢個係設計 retry logic 嗰陣必須考慮嘅嘢。
**使う場面：** マイクロサービス、イベント駆動アーキテクチャ、Kafka/SQS などのキュー処理

## 📝 例文 (Example Sentences)

1. HTTP の GET リクエストは冪等性（べきとうせい）を持つ。
   → 廣東語：HTTP 嘅 GET request 具有冪等性。

2. 決済（けっさい）処理は冪等性を保証しないと、二重請求（にじゅうせいきゅう）が発生する恐れがある。
   → 廣東語：Payment 處理如果唔保證冪等性，就有機會出現重複扣款嘅問題。

3. このAPIエンドポイントは冪等（べきとう）に設計されているので、タイムアウト後に安全に再試行できる。
   → 廣東語：呢個 API endpoint 係按照冪等原則設計，所以 timeout 之後可以安全咁 retry。

## 🗣️ 使い方・ニュアンス (Usage & Nuance)

**いつ使う：** 技術文書、API設計の議論、バックエンド開発、分散システムの設計レビューなどで頻繁に登場する。日常会話ではまず使わない。

**廣東語で言うと：** 冪等性 / Idempotent（通常英語のまま "idempotent" として話す場面が多い）。廣東語では「冪等」（冪等性）或者直接講 "idempotent" 都係自然。

**注意点：** 「安全（safe）」と混同しやすいが別の概念。HTTP では GET は「安全かつ冪等」、PUT は「冪等だが安全ではない」（副作用がある）、POST は「安全でも冪等でもない」というように区別する。

## 🔗 関連語 (Related Words)

- **安全性（あんぜんせい）** — サーバー状態を変更しない性質。冪等性とは独立した概念。
- **べき等（べきとう）** — 「冪等性」の形容詞的用法（冪等な操作）
- **再試行（さいしこう）/ Retry** — 冪等性が保証されていれば安全に行える操作
- **副作用（ふくさよう）/ Side effect** — 冪等性を破る原因になりやすい
